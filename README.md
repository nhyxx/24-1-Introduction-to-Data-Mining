# 피싱 URL 분류 모델
서울과학기술대학교 산업정보시스템전공 데이터마이닝 입문 팀 프로젝트

### 팀원
- 산업정보시스템전공 이혜린
- 산업정보시스템전공 차서윤
- 산업정보시스템전공 박정훈
- 산업정보시스템전공 권담이

### 사용 언어
R

### 1. 배경 및 필요성 
통신매체를 이용한 피싱 공격으로 금융 피해가 증가하는 가운데, 정상 도메인을 교묘히 변형한 피싱 URL은 육안으로 구별하기 어려움

### 2. 분석 목적
실제 서비스에 적용 가능한 피싱 URL 판별 기준을 세우는 것을 목표로 함
