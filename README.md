# 피싱 URL 분류 모델
서울과학기술대학교 산업정보시스템전공 데이터마이닝 입문 팀 프로젝트

### 팀원
- 산업정보시스템전공 이혜린
- 산업정보시스템전공 차서윤
- 산업정보시스템전공 박정훈
- 산업정보시스템전공 권담이

### 사용 언어
R

### 1. 배경 및 필요성 
전화·문자 등 통신매체를 이용한 피싱 공격으로 인한 금융 피해가 증가하고 있으며, 피싱 수법도 점차 고도화되고 있음
→ 정상 도메인 주소를 교묘하게 변형한 피싱 사이트 URL은 육안으로 쉽게 구별하기 어렵다는 문제에서 출발

### 2. 분석 목적
실제 서비스에 적용 가능한 피싱 URL 판별 기준을 세우는 것을 목표로 함

### 3. 사용 데이터 및 수집 방법
정상 도메인 URL 4000개
피싱 URL 도메인 4000개
